# 🚗 BMW Sales Dashboard (Excel)

## 📊 Project Overview
This project presents an interactive **Excel dashboard** analyzing BMW vehicle sales data from **2010–2024**.  
It highlights performance across regions, models, colors, transmission types, and yearly trends, providing clear business insights.

## 🔑 Key Metrics
- **Total Sales:** 50,000  
- **Average Vehicle Price:** $75,029  
- **Total Revenue:** $19.01 Billion  

## 📈 Insights
- 🌍 **Asia** leads in sales volume.  
- 🎨 **Red** is the most popular vehicle color.  
- 🚘 **BMW 7 Series** is the top-selling model.  
- ⚙️ Transmission sales are nearly balanced between **Automatic** and **Manual**.    

## 🛠️ Tools & Techniques
- Microsoft Excel  
- PivotTables & PivotCharts  
- Slicers for interactive filtering  
- Dashboard design & visualization best practices  


## 🚀 How to Use
1. Download the Excel file: **BMW PROJECT.xlsx**  
2. Open in Microsoft Excel.  
3. Use slicers to filter by **Region**.  
4. Explore interactive charts to uncover insights.
